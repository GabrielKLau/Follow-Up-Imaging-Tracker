# Follow-up Imaging Legislation Tracker

Tracks which U.S. states require insurers to cover follow-up imaging after an abnormal breast or
lung cancer screening with no patient cost-sharing, and what legislation is moving now. The site
is in `docs/`; the data pipeline is in `pipeline/`.

This tracker is a research tool, not legal advice.
